# Calculator

A calculator built with HTML, CSS, and JavaScript.  
Includes glassmorphism UI, smooth interactions, and full keyboard support.

FEATURES
  • Basic arithmetic (+, -, ×, ÷)
  • Decimal input
  • Chained operations
  • Backspace & clear
  • Keyboard support:
      0–9   → numbers
      .     → decimal
      + - * / → operators
      Enter → equals
      Esc   → clear
      Backspace → delete last digit


STATE SYSTEM
  display        Current visible value
  previousValue  Value stored before an operation
  operation      Active operator
  newNumber      Reset flag for next input
